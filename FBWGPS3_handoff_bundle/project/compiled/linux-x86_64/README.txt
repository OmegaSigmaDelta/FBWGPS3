FBWGPS3 Linux x86-64 build snapshot

Interactive desktop prototype:
  Run from the project root: ./compiled/linux-x86_64/fbw_game game
  Requires compatible SDL2 and libpng runtime libraries.
  Controls: menu Up/Down + Enter; Fireboy arrows + Space; Watergirl A/D/W; Escape pause/quit; M return to level menu; R retry; Enter next level after a win; Tab toggles two-player/solo mode in the menu and switches characters during solo play. One mapped game controller controls Fireboy and a second controls Watergirl (left stick/D-pad + A).
  The game writes fbw_progress.json in the current working directory.

The included test executables are development validation tools. This package is NOT a PS3 executable/PKG. Full original gameplay parity, device simulation, audio and PSL1GHT build are not yet complete.
